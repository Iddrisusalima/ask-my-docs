Overall agreement with the exact scan: 10/10 (100%)
100% at this corpus size, which is expected rather than reassuring. With
only a few hundred chunks the HNSW graph is small enough that a greedy
walk reaches the true nearest neighbours anyway. The approximation only
starts costing recall when the graph is large enough that the walk has
to skip meaningful portions of it. So this measurement confirms the
index is wired up correctly - it does not demonstrate that approximate
search is free.
Note the distance-to-similarity conversion above: cosine distance 0.0 means
identical direction, so similarity = 1 - distance puts these back on the original
scale where higher is better. src/retriever.py does this conversion once, at the
boundary, so nothing downstream has to remember which way round it is.
